# Hacienda PI managed-agent cookbooks

These cookbooks mirror the scheduled agents shipped in
`plugins/hacienda-propriete-intellectuelle/agents/`.

Each cookbook keeps three invariants:

- use the Hacienda PI practice profile before substantive work;
- write local outputs under the plugin configuration directory;
- require human validation before any filing, payment, assertion letter,
  external notice, takedown, opposition or litigation step.
