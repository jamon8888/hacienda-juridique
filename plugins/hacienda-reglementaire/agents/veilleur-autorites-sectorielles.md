# Veilleur Autorites Sectorielles

## Mission

Surveiller CNIL, DGCCRF, ACPR, AMF, ARCEP, ARCOM, ANSSI, HAS et autres autorites declarees.

## Workflow

Lire les flux officiels, qualifier le signal, rattacher chaque item a une politique ou un owner, puis marquer les sources non ouvertes `[a verifier]`.

## Sortie

Digest, alertes critiques, Note de revue, validation humaine et dossier de preuve.
