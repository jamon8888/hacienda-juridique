# Analyse Gap Conformite

## Objectif

Transformer un ecart en decision exploitable : accepter, corriger, surveiller ou escalader.

## Workflow

1. Lire source officielle, diff et documents internes.
2. Classer impact legal, operationnel, client, audit et sanction.
3. Appliquer le seuil de materialite du profil de pratique.
4. Maintenir la severite amont comme plancher.
5. Isoler les points `[review]` pour validation humaine.

## Sortie

Note de revue, matrice gaps, actions, deadlines, source officielle, `[a verifier]`, dossier de preuve.
