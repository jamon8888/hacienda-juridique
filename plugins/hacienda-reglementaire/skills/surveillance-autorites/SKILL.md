# Surveillance Autorites

## Objectif

Surveiller publications, sanctions, lignes directrices, consultations et priorites de controle des autorites du profil.

## Workflow

1. Lire watchlist.
2. Verifier sources officielles disponibles.
3. Classer chaque signal par materialite.
4. Relier le signal a une obligation, un gap ou une politique.
5. Documenter le dossier de preuve.

## Sortie

Digest, alertes, points `[review]`, points `[a verifier]`, Note de revue, Mode silencieux et Arbre de decision.
