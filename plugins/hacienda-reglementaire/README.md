# Reglementaire

## Mission

Veille réglementaire française et européenne : JORF, LODA, autorités sectorielles, changements de textes, écarts entre politiques internes et droit applicable.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-reglementaire:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `veille-jorf`
- `veille-reglementaire`
- `comparer-politique`
- `detecter-ecarts`
- `suivi-delais-commentaires`
- `digest-hebdomadaire`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
