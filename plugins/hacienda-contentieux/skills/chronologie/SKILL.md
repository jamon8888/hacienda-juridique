# Chronologie

## Sources À Vérifier

- Pièces du dossier : contrats, emails, courriers, actes, décisions, constats, factures.
- Code de procédure civile.
- Code civil.
- Code de justice administrative si applicable.
- Jurisprudence de la Cour de cassation ou du Conseil d'État si une date déclenche un régime discuté.

## Analyse

1. Extraire les événements datés et relier chaque événement à une pièce.
2. Séparer faits, actes procéduraux, mises en demeure, échanges transactionnels et décisions.
3. Identifier dates de départ des délais, interruptions, suspensions et échéances.
4. Signaler incohérences, trous probatoires et pièces manquantes.
5. Marquer `[à vérifier]` toute date non appuyée par une pièce.

## Points De Validation Humaine

- computation de délai ;
- prescription, forclusion, appel ou mise en état ;
- contradiction entre pièces ;
- événement central sans preuve directe.

## Dossier De Preuve

Inclure tableau date / événement / pièce / source / impact / statut avec références précises aux pièces.
