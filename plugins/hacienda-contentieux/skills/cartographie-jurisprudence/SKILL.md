# Cartographie Jurisprudence

## Sources À Vérifier

- Jurisprudence de la Cour de cassation.
- Jurisprudence du Conseil d'État.
- Décisions d'appel ou juridictions du fond lorsque pertinentes.
- Code de procédure civile, Code civil, Code de commerce ou Code de justice administrative selon le sujet.
- Bases privées uniquement comme orientation, jamais comme preuve finale.

## Analyse

1. Définir la question juridique et les critères de recherche.
2. Classer décisions favorables, défavorables, neutres, anciennes, récentes et isolées.
3. Identifier formation, date, publication, portée, faits comparables et solution.
4. Distinguer jurisprudence constante, décision isolée, revirement possible et lacune.
5. Marquer `[à vérifier]` toute décision non consultée dans sa source officielle.

## Points De Validation Humaine

- jurisprudence contradictoire ;
- décision non publiée ou isolée ;
- transposition incertaine aux faits ;
- stratégie de citation en assignation ou conclusions.

## Dossier De Preuve

Inclure tableau décision / juridiction / date / référence / solution / usage / statut avec source officielle.
