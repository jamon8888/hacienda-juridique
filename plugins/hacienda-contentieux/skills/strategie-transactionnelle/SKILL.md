# Stratégie Transactionnelle

## Sources À Vérifier

- Code civil.
- Code de procédure civile.
- Code de commerce si relation commerciale.
- Jurisprudence de la Cour de cassation.
- Pièces, chiffrage, échanges, mandat client et risques procéduraux.

## Analyse

1. Identifier objectifs, BATNA, risques, concessions possibles, lignes rouges et calendrier.
2. Vérifier validité de la transaction, concessions réciproques, confidentialité, renonciations et exécution.
3. Chiffrer exposition, coûts, délais, risques probatoires et valeur transactionnelle.
4. Préparer options : offre initiale, fallback, protocole, médiation ou poursuite.
5. Marquer `[à vérifier]` tout mandat, montant, source ou risque non confirmé.

## Points De Validation Humaine

- renonciation à action ou moyen ;
- confidentialité, non-dénigrement ou clause pénale ;
- transaction avec salarié, consommateur, personne vulnérable ou autorité ;
- écart entre risque juridique et objectif commercial.

## Dossier De Preuve

Inclure mandat, scénarios, chiffrage, projet de protocole, sources, concessions et validation humaine requise.
