# Analyse Moyens

## Sources À Vérifier

- Code de procédure civile.
- Code civil.
- Code de commerce si fond commercial.
- Code de justice administrative si contentieux administratif.
- Jurisprudence de la Cour de cassation et du Conseil d'État.
- Pièces et actes du dossier.

## Analyse

1. Identifier demandes, défenses, exceptions, fins de non-recevoir et incidents possibles.
2. Pour chaque moyen, lier fondement juridique, condition, pièce, charge de preuve et risque.
3. Tester recevabilité, compétence, prescription, preuve et chiffrage.
4. Distinguer moyens forts, moyens subsidiaires, moyens adverses anticipés et points faibles.
5. Marquer `[à vérifier]` tout fondement, délai, jurisprudence ou pièce non consulté.

## Points De Validation Humaine

- fin de non-recevoir ou exception de procédure ;
- moyen nouveau ou juridiquement instable ;
- jurisprudence contradictoire ;
- choix stratégique entre fond, incident et transaction.

## Dossier De Preuve

Inclure tableau moyen / source / condition / pièce / preuve / risque / validation humaine.
