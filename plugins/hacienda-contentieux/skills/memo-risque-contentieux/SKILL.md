# Mémo Risque Contentieux

## Sources À Vérifier

- Code de procédure civile.
- Code civil.
- Code de commerce ou Code de justice administrative selon le fond.
- Jurisprudence de la Cour de cassation et du Conseil d'État.
- Pièces, chiffrages, échanges transactionnels et actes.

## Analyse

1. Résumer faits, demandes, défenses, pièces et stade procédural.
2. Évaluer recevabilité, fond, preuve, quantum, exécution et réputation.
3. Proposer scénarios : succès, échec, transaction, incident, appel ou exécution.
4. Identifier points de levier, pièces à obtenir, coûts et prochaines étapes.
5. Marquer `[à vérifier]` tout chiffrage, délai, source ou hypothèse non confirmé.

## Points De Validation Humaine

- recommandation de transaction ou poursuite ;
- chiffrage significatif ou provision ;
- abandon de moyen ou concession ;
- risque stratégique, médiatique ou réglementaire.

## Dossier De Preuve

Inclure tableau risques / probabilité / impact / sources / pièces / actions / validation humaine.
