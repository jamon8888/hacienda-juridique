# Entretien De Démarrage Contentieux

## But

Créer ou mettre à jour le profil de pratique dans `~/.claude/plugins/config/hacienda-juridique/hacienda-contentieux/CLAUDE.md`.

## Questions

1. Quel est votre rôle : avocat contentieux, avocat conseil, juriste, direction juridique, autre professionnel ?
2. Quels contentieux traitez-vous : civil, commercial, social, administratif, fiscal, pénal des affaires, référé, arbitrage, médiation ?
3. Représentez-vous plutôt demandeur, défendeur, appelant, intimé, créancier, débiteur ou partie mise en cause ?
4. Quelles juridictions utilisez-vous : tribunal judiciaire, tribunal de commerce, cour d'appel, Cour de cassation, tribunal administratif, Conseil d'État ?
5. Quels actes voulez-vous produire : mise en demeure, assignation, requête, conclusions, bordereau, note d'audience, protocole ?
6. Quels risques imposent validation humaine : prescription, forclusion, compétence, appel, incident, transaction, chiffrage, pièce sensible ?
7. Quelles sources utilisez-vous : Code de procédure civile, Code civil, Code de commerce, Code de justice administrative, Cour de cassation, Conseil d'État, Doctrine, Dalloz, Lexis, modèles internes ?
8. Comment voulez-vous traiter les sources privées : orientation de recherche, citation possible, ou jamais sans source officielle ?
9. Comment organisez-vous les pièces : numérotation, bordereau, GED, RPVA, data room, dossier de preuve ?
10. Où doivent être conservés les dossiers de preuve, versions d'actes, pièces et calendriers procéduraux ?

## Sortie

Créer un profil complet sans marqueur `[A CONFIGURER]`, incluant juridictions, types de contentieux, actes, sources, pièces, seuils de validation humaine, stratégie transactionnelle et règles de conservation du dossier de preuve.
