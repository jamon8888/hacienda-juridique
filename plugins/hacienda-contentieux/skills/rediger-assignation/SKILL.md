# Rédiger Assignation

## Sources À Vérifier

- Code de procédure civile.
- Code civil.
- Code de commerce si litige commercial.
- Code de justice administrative si requête administrative plutôt qu'assignation.
- Jurisprudence de la Cour de cassation et du Conseil d'État selon le dossier.
- Pièces, bordereau, compétence, calendrier et chiffrage.

## Analyse

1. Vérifier juridiction, compétence, représentation, urgence, délai, prescription et mode d'introduction.
2. Structurer parties, faits, procédure, discussion, demandes, pièces et bordereau.
3. Relier chaque moyen à une source, une pièce et une demande.
4. Contrôler demandes accessoires, exécution provisoire, dépens, article 700 ou équivalent.
5. Marquer `[à vérifier]` toute compétence, demande, pièce ou jurisprudence non contrôlée.

## Points De Validation Humaine

- prescription, forclusion ou compétence ;
- référé, saisie, mesure conservatoire ou urgence ;
- demande chiffrée, astreinte ou exécution provisoire ;
- assignation exposant une stratégie ou pièce sensible.

## Dossier De Preuve

Inclure projet d'assignation, bordereau, sources, pièces, chiffrage, compétence, délais et statut.
