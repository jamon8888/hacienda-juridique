# Rédiger Conclusions

## Sources À Vérifier

- Code de procédure civile.
- Code civil.
- Code de commerce selon le fond.
- Code de justice administrative si mémoire administratif.
- Jurisprudence de la Cour de cassation et du Conseil d'État.
- Actes adverses, pièces, bordereaux, calendrier et décisions.

## Analyse

1. Identifier stade procédural, dernières écritures, demandes adverses et calendrier.
2. Structurer faits, procédure, discussion, moyens principaux, subsidiaires et dispositif.
3. Relier chaque affirmation à une pièce ou une source vérifiée.
4. Contrôler cohérence du dispositif, demandes chiffrées, fins de non-recevoir et incidents.
5. Marquer `[à vérifier]` toute citation, pièce, délai ou demande non contrôlée.

## Points De Validation Humaine

- changement de stratégie ou abandon d'un moyen ;
- moyen nouveau, incident, exception ou fin de non-recevoir ;
- dispositif, chiffrage ou demande sensible ;
- jurisprudence clé ou contradictoire.

## Dossier De Preuve

Inclure projet, versions, actes adverses, tableau moyens / pièces / sources, bordereau et validation humaine.
