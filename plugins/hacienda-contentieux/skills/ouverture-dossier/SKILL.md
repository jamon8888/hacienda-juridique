# Ouverture Dossier

## Sources À Vérifier

- Code de procédure civile.
- Code civil.
- Code de commerce si litige commercial.
- Code de justice administrative si contentieux administratif.
- Jurisprudence de la Cour de cassation et du Conseil d'État selon l'ordre juridictionnel.
- Pièces initiales, contrats, échanges, décisions, actes et calendrier.

## Analyse

1. Identifier parties, qualité, juridiction probable, demandes, défenses et urgence.
2. Qualifier fondement, procédure, compétence, prescription, forclusion et charge de preuve.
3. Lister pièces disponibles, pièces manquantes, pièces adverses attendues et risques probatoires.
4. Croiser procédure, fond, jurisprudence et pièces.
5. Marquer `[à vérifier]` toute date, source, compétence ou pièce non confirmée.

## Points De Validation Humaine

- délai de prescription ou forclusion ;
- compétence juridictionnelle incertaine ;
- référé, urgence ou mesure conservatoire ;
- pièce sensible, secret, confidentialité ou preuve contestable.

## Dossier De Preuve

Inclure fiche dossier, chronologie initiale, sources, pièces, hypothèses, charge de preuve, délais et statut de vérification.
