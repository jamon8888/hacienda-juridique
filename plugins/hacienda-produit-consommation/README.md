# Produit Consommation

## Mission

Revue juridique de lancement produit, marketing, parcours utilisateur, droit de la consommation, plateformes et pratiques commerciales.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-produit-consommation:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `revue-lancement-produit`
- `controle-allegations-marketing`
- `analyse-droit-consommation`
- `analyse-dark-patterns`
- `reviser-conditions-service`
- `analyse-risque-fonctionnalite`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
