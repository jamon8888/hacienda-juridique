# Revue Parcours Consommateur

## Avant De Commencer

Lire le profil de pratique et les maquettes disponibles. Signaler toute etape non lue `[a verifier]`.

## Contexte Dossier

Identifier audience, support, tunnel, consentement, prix, abonnement, desistement, informations obligatoires et confirmation.

## Sources A Verifier

Code de la consommation, DGCCRF, CNIL/RGPD, droit europeen consommation, screenshots, analytics, copy.

## Workflow

1. Decomposer le parcours.
2. Verifier information loyale et comprehensible.
3. Chercher asymetrie accepter/refuser.
4. Controler prix, frais, engagement et reconduction.
5. Lister corrections.

## Garde-Fous Et Escalade

Escalader dark patterns, mineurs, frais caches, consentement force, information precontractuelle absente.

## Format De Sortie

Table etape / risque / correction / source officielle / validation humaine / dossier de preuve.

## Dossier De Preuve

Conserver screenshots, versions, sources, decision et Note de revue.

## Arbre De Decision

- Etape manquante : `[a verifier]`.
- Friction trompeuse : STOP ou correction.
- Risque moyen : validation humaine.

## Mode silencieux

Ne pas redemander les seuils deja presents dans le profil de pratique.
