# Controle Marketplace Plateforme

## Avant De Commencer

Lire le profil de pratique, le modele plateforme et les politiques disponibles.

## Contexte Dossier

Identifier roles, vendeurs, consommateurs, moderation, avis, classement, frais, KYC, contenu et reclamations.

## Sources A Verifier

Code de la consommation, DSA, droit europeen plateforme, DGCCRF, Code de commerce, politiques internes et source officielle.

## Workflow

1. Qualifier le role de plateforme.
2. Verifier information consommateur.
3. Controler avis, classement et moderation.
4. Controler obligations vendeurs.
5. Lister gaps et owners.

## Garde-Fous Et Escalade

Escalader contenus illicites, avis manipules, classement opaque, vendeurs non verifies, DSA ou mineurs.

## Format De Sortie

Matrice obligations / preuve / ecart / action / validation humaine / Note de revue.

## Dossier De Preuve

Conserver politiques, screenshots, sources, decisions et `[a verifier]`.

## Arbre De Decision

- Role incertain : qualification.
- Obligation manquante : correction.
- Risque DSA : escalade.

## Mode silencieux

Reutiliser le type de plateforme du profil de pratique.
