# Analyse Prix Promotions

## Avant De Commencer

Lire le profil de pratique, la page prix et les conditions. Tout prix ou historique non fourni reste `[a verifier]`.

## Contexte Dossier

Collecter prix, reference, remise, duree, frais, abonnement, reconduction, resiliation, taxes, canal et audience.

## Sources A Verifier

Code de la consommation, DGCCRF, droit europeen consommation, Code de commerce, screenshots, historiques de prix.

## Workflow

1. Decrire offre et prix.
2. Verifier prix de reference et reduction.
3. Controler frais et taxes.
4. Controler abonnement et resiliation.
5. Identifier corrections avant publication.

## Garde-Fous Et Escalade

Escalader prix barres non justifies, frais caches, urgence artificielle, reconduction peu claire, offre mineurs.

## Format De Sortie

Table element / preuve / risque / correction / source officielle / validation humaine / Note de revue.

## Dossier De Preuve

Conserver pages, historiques, screenshots, sources et decision.

## Arbre De Decision

- Historique absent : `[a verifier]`.
- Frais caches : STOP.
- Prix clair : GO sous reserve de preuve.

## Mode silencieux

Utiliser les seuils connus, mais demander preuve de prix.
