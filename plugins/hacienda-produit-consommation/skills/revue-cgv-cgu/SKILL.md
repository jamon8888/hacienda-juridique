# Revue CGV CGU

## Avant De Commencer

Lire le profil de pratique, le contrat et le parcours associe. Les clauses non lues restent `[a verifier]`.

## Contexte Dossier

Identifier cible B2C/B2B, abonnement, prix, responsabilite, garanties, desistement, resiliation, donnees, contenu utilisateur.

## Sources A Verifier

Code de la consommation, Code civil, Code de commerce, CNIL/RGPD, documents produit, source officielle des regles citees.

## Workflow

1. Lire structure et clauses sensibles.
2. Comparer au parcours reel.
3. Chercher clauses abusives ou incoherentes.
4. Verifier desistement, resiliation, prix, garantie.
5. Proposer redlines ou questions.

## Garde-Fous Et Escalade

Escalader clause abusive probable, renonciation consommateur, limitation excessive, reconduction ou frais obscurs.

## Format De Sortie

Clause, risque, source, redline proposee, validation humaine, dossier de preuve et Note de revue.

## Dossier De Preuve

Conserver version, redline, sources et points `[review]`.

## Arbre De Decision

- Clause manquante : `[a verifier]`.
- Clause bloquante : corriger.
- Clause sensible : validation humaine.

## Mode silencieux

Appliquer le playbook du profil de pratique.
