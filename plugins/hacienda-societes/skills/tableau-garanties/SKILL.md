# Tableau Garanties

## Sources À Vérifier

- Code civil.
- Code de commerce.
- SPA, garantie d'actif et de passif, annexes, disclosure letter et data room.
- Statuts, comptes, contrats clés et litiges.
- Jurisprudence de la Cour de cassation.

## Analyse

1. Identifier déclarations fondamentales, garanties business, exclusions, plafonds, franchises et durées.
2. Relier chaque garantie aux pièces de data room, disclosure et risques identifiés.
3. Vérifier mécanismes d'indemnisation, notification, conduite des réclamations et limitations.
4. Croiser Code civil, Code de commerce, contrat et jurisprudence.
5. Marquer `[à vérifier]` toute garantie, exception ou pièce non contrôlée.

## Points De Validation Humaine

- plafond, franchise, durée ou garantie fondamentale ;
- disclosure insuffisante ou data room incomplète ;
- litige, fiscalité, social, propriété intellectuelle ou dette ;
- contradiction entre rapport d'audit et garantie.

## Dossier De Preuve

Inclure tableau garanties / risques / pièces / sources / exceptions, SPA, annexes, data room et statut.
