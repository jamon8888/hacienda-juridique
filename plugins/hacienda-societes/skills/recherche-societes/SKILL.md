# Recherche Sociétés

## Sources À Vérifier

- Code de commerce.
- Code civil.
- Code monétaire et financier si titres financiers ou opération régulée.
- Statuts, pacte, registres, décisions et table de capitalisation.
- RCS-INPI, BODACC, Kbis et bénéficiaires effectifs.
- Jurisprudence de la Cour de cassation.

## Analyse

1. Qualifier la forme sociale, l'opération, les parties et le stade du dossier.
2. Identifier les textes Code de commerce et Code civil applicables.
3. Vérifier statuts, pacte, registres, RCS-INPI et BODACC si opposabilité ou formalité.
4. Rechercher la jurisprudence de la Cour de cassation lorsque le point est interprétatif.
5. Marquer `[à vérifier]` toute source, pièce ou version non consultée.

## Points De Validation Humaine

- modification statutaire, émission de titres ou closing ;
- conflit d'associés, abus de majorité/minorité ou convention réglementée ;
- pacte, gouvernance, cession ou garantie de passif ;
- contradiction entre texte, statuts, pacte, registre et pratique.

## Dossier De Preuve

Inclure références, pièces, versions, RCS-INPI, BODACC, statuts, pacte, décisions, date de consultation et statut de vérification.
