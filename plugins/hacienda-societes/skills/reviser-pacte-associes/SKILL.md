# Réviser Pacte Associés

## Sources À Vérifier

- Code de commerce.
- Code civil.
- Statuts, pacte, table de capitalisation et contrats liés.
- RCS-INPI si pouvoirs, dirigeants ou forme sociale doivent être confirmés.
- Jurisprudence de la Cour de cassation.

## Analyse

1. Identifier parties, titres concernés, gouvernance, durée et articulation avec les statuts.
2. Revoir préemption, agrément, inaliénabilité, tag, drag, sortie forcée, bad leaver et anti-dilution.
3. Contrôler sanctions, promesses, prix, pouvoirs, conflit statuts/pacte et opposabilité.
4. Croiser Code de commerce, Code civil, statuts, pacte et jurisprudence.
5. Marquer `[à vérifier]` toute table de capitalisation, version ou clause non contrôlée.

## Points De Validation Humaine

- clause de sortie forcée, exclusion, bad leaver ou non-concurrence ;
- conflit entre pacte et statuts ;
- valorisation, prix, promesse ou mécanisme complexe ;
- investisseur minoritaire ou gouvernance sensible.

## Dossier De Preuve

Inclure pacte, statuts, table de capitalisation, clauses sensibles, sources, jurisprudence et validation humaine requise.
