# Societes

## Mission

Assister les opérations de droit des sociétés, gouvernance, M&A et vie sociale.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-societes:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `audit-societes`
- `reviser-pacte-associes`
- `reviser-cession-titres`
- `preparer-assemblee`
- `rediger-proces-verbal`
- `checklist-closing`
- `calendrier-vie-sociale`
- `tableau-garanties`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
