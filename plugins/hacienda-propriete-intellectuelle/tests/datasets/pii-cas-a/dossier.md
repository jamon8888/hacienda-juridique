# Politique interne open source — projet ATLANTIS (fictif)

**Référence interne :** OSS-POL-2026-03
**Émetteur :** Direction Technique
**Destinataires :** équipes Engineering & Juridique

---

## 1. Périmètre

Cette politique précise les règles d'usage des composants open source dans
les produits de la société ATLANTIS SAS, à compter de janvier 2026.

Elle s'applique à toutes les équipes Engineering :

- Équipe Backend : Sophie Martin, Pierre Dubois, Marie Lefevre, Antoine Rousseau, Camille Bernard, Julien Moreau
- Équipe Frontend : Léa Petit, Hugo Roux, Chloé Garnier, Mathieu Lemoine, Émilie Chevalier
- Équipe DevOps : Nicolas Vincent, Laure Faure, Thibault Marchand
- Équipe Data : Aurélie Nguyen, Romain Picard, Sarah Lambert, Valentin Robert
- Équipe Mobile : Clara Mercier, Benjamin Olivier, Élise Dumont
- Équipe QA : Lucas Joly, Pauline Caron, Adrien Riviere, Manon Schmitt
- Architectes : Cédric Vidal, Marion Aubert, Olivier Lacroix, Vanessa Boyer

## 2. Licences autorisées

Liste blanche par défaut : MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0, ISC.

Liste grise (validation case par case par le juridique) : LGPL-2.1, LGPL-3.0,
MPL-2.0, EPL-2.0.

Liste rouge (interdiction sauf isolation stricte) : GPL-2.0, GPL-3.0, AGPL-3.0,
SSPL.

## 3. Workflow

Toute introduction d'un composant en liste grise ou rouge doit passer par un
ticket Jira `OSS-REVIEW-*` et une validation juridique formelle.

## 4. Contact

Pour toute question, contacter l'équipe juridique via le canal Slack
`#legal-oss` ou par email à legal@atlantis-fictif.example.
