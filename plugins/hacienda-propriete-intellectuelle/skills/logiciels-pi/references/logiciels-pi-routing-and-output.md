# Logiciels PI - routing and output

Reference de travail non normative. Elle sert d'aide-memo rapide pour le
routage et les blocs de sortie. En cas d'ecart, seul
`plugins/hacienda-propriete-intellectuelle/skills/logiciels-pi/SKILL.md`
fait foi.

## 1. When to stay in logiciels-pi

- titularite initiale L.113-9
- droits d'utilisation et exceptions
- triage OSS de haut niveau
- signaux SaaS / data / base
- choix de la prochaine brique

## 2. When to route away

- `revue-open-source` : inventaire detaille, conflits, obligations, SBOM,
  remediation
- `revue-logiciel-donnees` : chaine de droits code/data/base, fondateurs,
  freelancers, contrats
- `cession-droit-auteur` : besoin principal = cession
- `licence-droit-auteur` : besoin principal = licence
- `contrefacon-droit-auteur` : besoin principal = reprise, similitudes,
  action ou defense en contrefacon logicielle

## 3. Core output blocks

- `Software Regime Snapshot`
- `Facts and Contract Review`
- `Initial Ownership Map`
- `Use Rights and Statutory Exceptions`
- `OSS Triage Gate`
- `SaaS, Data and Database Signals`
- `Business-Model Risks`
- `Next Step Routing`
- `Human Validation`
