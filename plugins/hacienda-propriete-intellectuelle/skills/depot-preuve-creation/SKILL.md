# Depot Preuve Creation

## Objectif

Organiser preuve de creation, contributeurs, dates, cessions, versions et depot eventuel.

## Workflow

1. Identifier oeuvre, auteurs, date, versions et supports.
2. Collecter contrats, commits, maquettes, exports et attestations.
3. Relever lacunes de chaine de droits.
4. Marquer `[a verifier]` tout fait non documente.
5. Demander validation humaine avant depot ou declaration externe.

## Sortie

Dossier de preuve, checklist, gaps titularite, source officielle si depot, Note de revue.
