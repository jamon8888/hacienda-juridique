# Grille des pieces par type de dossier

Cette grille aide a construire un dossier probatoire adapte au type de droit ou de litige. Elle ne remplace pas une verification humaine du contexte ni une revue des sources effectivement consultees.

## Oeuvre graphique

### Faits a documenter

- date de creation ;
- auteur ou equipe creative ;
- versions successives ;
- remise au client ou publication ;
- cession ou licence eventuelle.

### Pieces utiles

- croquis, moodboards, maquettes, exports source ;
- fichiers natifs dates ;
- emails de brief et de validation ;
- devis, bon de commande, facture ;
- livrables agence ;
- cession de droits ou clauses contractuelles ;
- enveloppe Soleau / e-Soleau, constat ou horodatage technique si disponibles.

### Incertitudes frequentes

- auteur reel different du signataire commercial ;
- version diffusee differente de la version archivee ;
- cession absente ou incomplete ;
- date de premiere diffusion `[à vérifier]`.

## Logiciel

### Faits a documenter

- date des premiers developpements ;
- contributeurs et roles ;
- versions ou modules pertinents ;
- modalites de livraison, publication ou exploitation ;
- chaine de droits sur code, assets et dependances.

### Pieces utiles

- depot Git, commits, tags, releases ;
- tickets, merges, journaux CI/CD ;
- cahier de laboratoire ou journal R&D ;
- contrats salarie, freelance, associes fondateurs, cession IP ;
- emails de livraison ou de recette ;
- archives de build, paquets, captures de version ;
- inventaire de dependances et licences entrantes.

### Incertitudes frequentes

- auteur de commit non identique a l'auteur juridique ;
- code tiers integre sans trace claire ;
- module invoque non rattache a la date contestee ;
- contribution externe sans cession exploitable.

## Marque / usage

### Faits a documenter

- date de premier usage allegue ;
- signe utilise ;
- produits ou services vises ;
- territoire et canaux ;
- continuite ou intensite de l'usage.

### Pieces utiles

- captures de site, marketplace, reseaux sociaux ;
- packagings, etiquettes, catalogues ;
- factures, bons de livraison, devis ;
- campagnes email, publicites, analytics de diffusion ;
- contrats de distribution ou de licence ;
- constat ou archivage de pages si disponible.

### Incertitudes frequentes

- usage localise mais perimetre commercial incertain ;
- signe variable selon supports ;
- dates de mise en ligne seulement supposees ;
- lien entre usage et titulaire `[à vérifier]`.

## Opposition / nullite

### Faits a documenter

- droit invoque ;
- date pertinente ;
- signe ou oeuvre oppose ;
- pieces justifiant l'anteriorite, l'usage ou la titularite ;
- evenements de procedure deja intervenus.

### Pieces utiles

- certificats ou extraits de depot effectivement consultes ;
- preuves d'usage et de diffusion ;
- preuves de creation et de chaine de droits ;
- captures comparatives ;
- courrier de procedure, notifications, delais ;
- constats, archives et attestations utiles.

### Incertitudes frequentes

- piece procedurale mentionnee mais non consultee ;
- confusion entre droit invoque et piece disponible ;
- date pivot du dossier insuffisamment documentee ;
- lien entre partie invoquante et titulaire reel.

## Dossier precontentieux

### Faits a documenter

- faits reproches ou contestes ;
- chronologie des echanges ;
- droits invoques ou contestes ;
- preuves deja detenues ;
- objectif pratique : negotiation, mise en demeure, preparation contentieuse.

### Pieces utiles

- synthese factuelle datee ;
- courriers, emails, captures, contrats, CGV, briefs ;
- preuves de creation, d'usage, de livraison ou de diffusion ;
- elements de chiffrage ou d'impact commercial ;
- constat, horodatage ou archivage quand pertinent ;
- note interne sur pieces manquantes et priorites.

### Incertitudes frequentes

- allegation grave sans piece immediate ;
- prejudice affirme sans base de calcul exploitable ;
- correspondance incomplete ;
- dossier prepare trop vite pour usage externe sans revue humaine.
