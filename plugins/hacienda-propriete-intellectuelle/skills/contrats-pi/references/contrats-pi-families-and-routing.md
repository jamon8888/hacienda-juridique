# Contrats PI - families and routing

## 1. Family selection

- `patent-tech-transfer`
  - licence de brevet
  - cession de brevet
  - licence de savoir-faire
  - transfert de technologie

- `nda-secret-knowhow`
  - NDA
  - accord de confidentialite
  - partage de secret d'affaires

- `rnd-collaboration`
  - recherche conjointe
  - innovation collaborative
  - partage background / foreground

- `trademark-coexistence-franchise`
  - coexistence de marques
  - franchise avec coeur PI
  - licence de marque structurelle

- `mta-life-sciences`
  - MTA biotech/pharma
  - transfert de materiel sensible

## 2. When to route away

- `revue-clause-pi`
  - quand la PI n'est qu'un bloc dans un contrat plus large
- `cession-droit-auteur`
  - cession auteur pure
- `licence-droit-auteur`
  - licence auteur pure
- `bases-de-donnees`
  - contrat centre sur le droit sui generis BDD
- `revue-logiciel-donnees`
  - chaine de droits logiciel / data

## 3. Common output blocks

- `Contract Snapshot`
- `Critical PI Terms`
- `Registration and Opposability Actions`
- `Competition and Regulatory Issues`
- `Human Validation`
