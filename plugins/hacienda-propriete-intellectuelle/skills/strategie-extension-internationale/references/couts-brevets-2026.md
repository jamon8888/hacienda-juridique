## Accord de Londres (2001 — entré en vigueur 2008)

L'Accord de Londres allège l'obligation de traduction post-délivrance EP :

- **France / Allemagne / Royaume-Uni** : acceptent un EP délivré en EN, FR
  ou DE **sans traduction supplémentaire** (description et revendications).
- **Pays récents adhérents** (acceptation partielle — souvent revendications
  dans la langue nationale, description acceptée en EN/FR/DE) : SE, NL, IS,
  LV, LT, NO, AL, MC, HR, SI, MT, FI.
- **Avantage économique** : économies validations pour les 3 pays « cœur »
  FR/DE/GB de l'ordre de 1 500-3 000€ par validation (traduction certifiée
  évitée).

**Implication stratégique** : pour une couverture EU minimale FR/DE/UK, le
post-délivrance EP est dramatiquement plus économique que toute autre
combinaison de 3 pays EU.

## Frais avocat / mandataire indicatifs

| Poste | Fourchette HT |
|---|---|
| Cabinet PI parisien établi (taux horaire) | 250-450€/heure |
| Préparation dépôt EP (forfait) | ~5-15k€ HT |
| Préparation dépôt PCT (forfait) | ~6-18k€ HT |
| Réponse à notification examinateur OEB | ~2-5k€ HT par notification |
| Réponse à notification USPTO Office Action | ~2-4k€ HT par notification |
| Réponse à notification CNIPA (mandataire CN) | ~1.5-3k€ HT par notification |
| Procédure d'opposition OEB (défense, ~3 ans) | ~30-100k€ HT |

**Règle d'estimation rapide** : doubler les taxes officielles pour obtenir
un budget global incluant frais cabinet (sauf cabinets premium ou dossiers
techniquement complexes — biotech, semi-conducteurs — où le multiplicateur
peut atteindre 3-4x).
