# Analyse Plus-Value

## Sources À Vérifier

- CGI.
- LPF.
- BOFiP.
- Jurisprudence du Conseil d'État.

## Analyse

1. Identifier actif, cédant, régime fiscal, date d'acquisition, prix et frais.
2. Qualifier plus-value professionnelle, mobilière, immobilière ou régime spécial.
3. Vérifier abattements, exonérations, reports, sursis ou droits d'enregistrement.
4. Croiser CGI et BOFiP.
5. Marquer `[à vérifier]` les calculs ou pièces non confirmés.

## Points De Validation Humaine

- montant significatif ;
- régime d'exonération ;
- apport-cession ;
- cession intragroupe ;
- résidence fiscale.

## Dossier De Preuve

Inclure textes, doctrine, calculs, pièces, date de consultation et statut.
