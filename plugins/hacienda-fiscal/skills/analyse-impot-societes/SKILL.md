# Analyse Impôt Sociétés

## Sources À Vérifier

- CGI.
- LPF.
- BOFiP IS.
- Jurisprudence du Conseil d'État.

## Analyse

1. Identifier l'entité, l'exercice, l'opération et les montants.
2. Qualifier le traitement fiscal : produit, charge, provision, régime spécial ou intégration.
3. Vérifier les articles CGI et commentaires BOFiP.
4. Rechercher les décisions du Conseil d'État si le point est interprétatif.
5. Marquer `[à vérifier]` les éléments non confirmés.

## Points De Validation Humaine

- restructuration ;
- prix de transfert ;
- intégration fiscale ;
- limitation de charges financières ;
- enjeu significatif.
