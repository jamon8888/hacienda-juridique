# Revue Marche Public

## Objectif

Analyser procedure, publicite, selection, clauses, criteres, execution, avenants et recours potentiels.

## Workflow

1. Lire avis, DCE, RC, CCAP/CCTP, questions-reponses et decision.
2. Verifier source officielle ou profil acheteur.
3. Identifier irregularites, risques et delais.
4. Marquer `[review]` les choix de strategie.
5. Exiger validation humaine avant courrier ou recours.

## Sortie

Tableau risques, delais, options, points `[a verifier]`, Note de revue et dossier de preuve.
