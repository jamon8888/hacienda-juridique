# Analyser Distribution

## Sources À Vérifier

- Code civil.
- Code de commerce.
- Code de la consommation si vente au consommateur.
- Jurisprudence de la Cour de cassation.
- Contrats, annexes, conditions commerciales, objectifs, territoire et historique de relation.

## Analyse

1. Qualifier le modèle : distribution sélective, exclusive, franchise, agent commercial, commission-affiliation, apporteur.
2. Vérifier exclusivité, objectifs, territoire, prix, stock, approvisionnement, non-concurrence et fin de relation.
3. Identifier risques de dépendance économique, déséquilibre significatif ou rupture brutale.
4. Croiser Code de commerce, contrat, pratique réelle et jurisprudence.
5. Marquer `[à vérifier]` toute donnée commerciale, historique ou clause non contrôlée.

## Points De Validation Humaine

- exclusivité, prix imposé, dépendance économique ou déséquilibre significatif ;
- rupture ou non-renouvellement ;
- franchise, agent commercial ou indemnité de fin de contrat ;
- réseau international ou droit de la concurrence.

## Dossier De Preuve

Inclure contrats, historique, chiffres, échanges, Code de commerce, jurisprudence, hypothèses et statut.
