# Réviser Bail Commercial

## Sources À Vérifier

- Code de commerce.
- Code civil.
- Jurisprudence de la Cour de cassation.
- Bail, état des lieux, annexes, diagnostics, avenants, congés et échanges.

## Analyse

1. Identifier locaux, activité autorisée, durée, loyer, charges, dépôt, destination et garanties.
2. Vérifier durée 3-6-9, renouvellement, congé, révision, indexation, cession, sous-location et travaux.
3. Repérer clause résolutoire, charges récupérables, indemnité d'éviction et obligations de délivrance.
4. Croiser Code de commerce, Code civil, bail et jurisprudence.
5. Marquer `[à vérifier]` toute date d'échéance, annexe ou clause non contrôlée.

## Points De Validation Humaine

- congé, renouvellement, indemnité d'éviction ou déplafonnement ;
- clause résolutoire, impayé ou contentieux ;
- travaux, destination ou cession du fonds ;
- bail de forte valeur ou actif stratégique.

## Dossier De Preuve

Inclure bail, annexes, échéancier, sources Code de commerce / Code civil, jurisprudence, pièces et statut.
