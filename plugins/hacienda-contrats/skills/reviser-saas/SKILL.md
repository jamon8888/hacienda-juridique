# Réviser SaaS

## Sources À Vérifier

- Code civil.
- Code de commerce.
- Code de la consommation si offre B2C.
- RGPD/CNIL si traitement de données personnelles.
- Jurisprudence de la Cour de cassation.
- Contrat SaaS, DPA, SLA, politique sécurité, documentation produit et annexes.

## Analyse

1. Identifier services, périmètre, niveaux de service, support, disponibilité et exclusions.
2. Vérifier responsabilité, garanties, réversibilité, audit, sous-traitance, sécurité et données.
3. Contrôler facturation, renouvellement, suspension, résiliation et restitution des données.
4. Croiser contrat avec Code civil, Code de commerce, Code de la consommation et obligations données.
5. Marquer `[à vérifier]` toute annexe, métrique SLA ou traitement non documenté.

## Points De Validation Humaine

- limitation de responsabilité trop basse ou illimitée ;
- sécurité, données sensibles, hébergement ou sous-traitance critique ;
- réversibilité insuffisante ;
- droit étranger, client régulé ou service critique.

## Dossier De Preuve

Inclure contrat, DPA, SLA, annexes techniques, sources, clauses redlinées, hypothèses et statut de vérification.
