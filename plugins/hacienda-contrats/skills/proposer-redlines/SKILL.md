# Proposer Redlines

## Sources À Vérifier

- Code civil.
- Code de commerce.
- Code de la consommation si clause B2C.
- Jurisprudence de la Cour de cassation.
- Playbook interne, position client/fournisseur, clause source et versions précédentes.

## Analyse

1. Identifier la position représentée, l'objectif commercial et le niveau de risque acceptable.
2. Classer la clause : responsabilité, garantie, confidentialité, résiliation, propriété, données, paiement.
3. Proposer redline minimaliste, équilibrée et protectrice si utile.
4. Justifier chaque changement par risque, source officielle ou cohérence contractuelle.
5. Marquer `[à vérifier]` toute justification juridique non contrôlée.

## Points De Validation Humaine

- clause contraire au playbook ou au mandat ;
- concession commerciale significative ;
- limitation de responsabilité, indemnisation ou exclusion ;
- clause consommateur ou secteur régulé.

## Dossier De Preuve

Inclure clause source, clause proposée, justification, sources, hypothèses de négociation et validation humaine requise.
