# Réviser Contrat

## Sources À Vérifier

- Code civil.
- Code de commerce.
- Code de la consommation si consommateur ou non-professionnel.
- Jurisprudence de la Cour de cassation.
- Contrat, annexes, bons de commande, cahier des charges et emails de négociation.

## Analyse

1. Identifier parties, objet, durée, prix, obligations principales et annexes.
2. Cartographier clauses sensibles : responsabilité, garanties, confidentialité, propriété, résiliation, pénalités.
3. Comparer chaque risque au Code civil, au Code de commerce et à la jurisprudence.
4. Proposer niveau de risque, position de négociation et clause alternative lorsque utile.
5. Marquer `[à vérifier]` toute source ou version contractuelle non contrôlée.

## Points De Validation Humaine

- limitation de responsabilité ou exclusion de garantie ;
- clause déséquilibrée, potestative ou incompatible avec le modèle économique ;
- contrat de forte valeur ou dépendance opérationnelle ;
- arbitrage commercial contraire au risque juridique.

## Dossier De Preuve

Inclure contrat source, version revue, tableau clauses / risques / sources, décisions, hypothèses et validation humaine requise.
