# Recherche Contractuelle

## Sources À Vérifier

- Code civil.
- Code de commerce.
- Code de la consommation si consommateur, CGV/CGU ou pratiques commerciales.
- Jurisprudence de la Cour de cassation.
- JORF/LODA pour les réformes ou textes récents.
- Projet contractuel et pièces de négociation.

## Analyse

1. Qualifier le contrat, les parties, le contexte B2B/B2C et le droit applicable.
2. Identifier les textes du Code civil, du Code de commerce et du Code de la consommation pertinents.
3. Rechercher la jurisprudence de la Cour de cassation lorsque la clause ou le risque est interprétatif.
4. Croiser le texte, la clause, les pièces et la position de négociation.
5. Marquer `[à vérifier]` toute source, version contractuelle ou pièce non consultée.

## Points De Validation Humaine

- clause de responsabilité, garantie, pénalité, résiliation ou indemnisation ;
- contrat stratégique, forte valeur ou dépendance économique ;
- contradiction texte / jurisprudence / position commerciale ;
- clause B2C ou risque de clause abusive.

## Dossier De Preuve

Inclure sources officielles, références, version contractuelle, clauses analysées, pièces, date de consultation et statut de vérification.
