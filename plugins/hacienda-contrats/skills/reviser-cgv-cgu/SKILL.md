# Réviser CGV CGU

## Sources À Vérifier

- Code civil.
- Code de commerce.
- Code de la consommation.
- Jurisprudence de la Cour de cassation.
- CGV/CGU, parcours de souscription, tunnel de commande, mentions légales et politique de remboursement.

## Analyse

1. Qualifier B2B, B2C, marketplace, abonnement, e-commerce ou prestation numérique.
2. Vérifier formation du contrat, information précontractuelle, prix, livraison, rétractation et résiliation.
3. Contrôler clauses abusives, garanties légales, responsabilité, reconduction et modification unilatérale.
4. Comparer texte des CGV/CGU, parcours utilisateur et exigences Code de la consommation.
5. Marquer `[à vérifier]` tout écran, version ou source non consulté.

## Points De Validation Humaine

- clauses B2C, rétractation, garanties légales ou abonnement ;
- dark patterns, pratiques commerciales, marketplace ou intermédiaire ;
- limitation de responsabilité ou clause abusive ;
- divergence entre CGV et parcours réellement affiché.

## Dossier De Preuve

Inclure CGV/CGU, captures ou description du parcours, Code civil, Code de commerce, Code de la consommation, jurisprudence et statut.
