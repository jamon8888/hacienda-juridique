# Réviser NDA

## Sources À Vérifier

- Code civil.
- Code de commerce si secret des affaires ou relations commerciales.
- Jurisprudence de la Cour de cassation.
- NDA, annexes, informations protégées, contexte de négociation et durée.

## Analyse

1. Identifier parties, informations confidentielles, exclusions, bénéficiaires et finalité.
2. Vérifier durée, restitution, destruction, preuve, sanctions et articulation secret des affaires.
3. Contrôler clauses de non-sollicitation, non-contournement, exclusivité ou non-concurrence déguisée.
4. Proposer redlines selon position divulgateur ou récepteur.
5. Marquer `[à vérifier]` toute hypothèse factuelle ou source non consultée.

## Points De Validation Humaine

- clause de pénalité excessive ou insuffisante ;
- non-concurrence, non-sollicitation ou exclusivité ;
- informations stratégiques, M&A, levée de fonds ou technologie sensible ;
- droit étranger ou juridiction étrangère.

## Dossier De Preuve

Inclure version du NDA, clauses sensibles, sources Code civil / Code de commerce, pièces de contexte et statut.
