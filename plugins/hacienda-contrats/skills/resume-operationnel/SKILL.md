# Résumé Opérationnel

## Sources À Vérifier

- Contrat et annexes.
- Code civil.
- Code de commerce.
- Code de la consommation si consommateur ou CGV/CGU.
- Jurisprudence de la Cour de cassation pour les clauses sensibles.

## Analyse

1. Extraire parties, objet, durée, prix, renouvellement, résiliation, obligations et dépendances.
2. Résumer les risques opérationnels : service, livraison, paiement, responsabilité, données, sécurité, sortie.
3. Identifier actions avant signature, points de suivi et propriétaires internes.
4. Lier les risques juridiques aux sources et clauses concernées.
5. Marquer `[à vérifier]` toute donnée non confirmée dans les pièces.

## Points De Validation Humaine

- recommandation de signature, refus ou escalade ;
- risque financier, opérationnel ou réglementaire important ;
- clause de responsabilité, résiliation, exclusivité ou données ;
- divergence entre résumé métier et version contractuelle.

## Dossier De Preuve

Inclure contrat, annexes, tableau obligations / risques / actions, sources vérifiées, hypothèses et statut.
