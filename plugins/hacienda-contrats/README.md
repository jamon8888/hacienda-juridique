# Contrats

## Mission

Revue et rédaction de contrats commerciaux français : CGV, CGU, SaaS, NDA, distribution, prestations, baux commerciaux, clauses sensibles.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-contrats:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `reviser-contrat`
- `reviser-nda`
- `reviser-saas`
- `reviser-cgv-cgu`
- `analyser-distribution`
- `analyser-rupture-brutale`
- `reviser-bail-commercial`
- `proposer-redlines`
- `resume-operationnel`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
