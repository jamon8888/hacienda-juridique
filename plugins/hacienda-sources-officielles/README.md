# Sources Officielles

## Mission

Fournir le socle de preuve officiel pour Légifrance, BOFiP, JORF, KALI et jurisprudence officielle.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-sources-officielles:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `verifier-citation`
- `dossier-preuve`
- `verifier-version`
- `cartographier-sources`
- `classer-autorite`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
