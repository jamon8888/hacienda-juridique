# Cartographier Les Sources

## Objectif

Préparer une stratégie de recherche fiable avant de rédiger une analyse
juridique. La cartographie doit distinguer sources primaires, sources
administratives, jurisprudence et sources éditoriales.

## Procédure

1. Reformuler la question en concepts juridiques et mots-clés français.
2. Identifier les sources officielles obligatoires.
3. Indiquer les bases documentaires professionnelles utiles pour repérage ou
   doctrine.
4. Proposer l'ordre de consultation.
5. Lister les risques d'angle mort : version, compétence, régime spécial,
   jurisprudence récente, doctrine administrative, convention collective.

## Format De Sortie

```markdown
## Cartographie Des Sources

**Question :** ...

### Sources Officielles Prioritaires

| Source | Pourquoi | Tool Hacienda | Requête proposée |
|---|---|---|---|
| ... | ... | ... | ... |

### Sources Professionnelles Utiles

- ...

### Risques D'Angle Mort

- ...

### Ordre Recommandé

1. ...
```

## Garde-Fous

- Ne pas remplacer la source officielle par une base éditoriale lorsqu'une
  source primaire existe.
- Pour le fiscal, BOFiP doit être cartographié en plus des textes.
- Pour le social, vérifier les conventions collectives et les sources KALI/IDCC.
