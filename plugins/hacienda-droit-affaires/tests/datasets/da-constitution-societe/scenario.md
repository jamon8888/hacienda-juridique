## Scénario fictif
La société en projet est désignée provisoirement **Lynore Studio**.
Le nom commercial utilisé depuis septembre 2025 est **LYNORE ATELIER**.
Le SIREN fictif utilisé comme identifiant interne est **532 746 819**.
L'activité envisagée est l'édition d'une plateforme SaaS B2B de gestion de
catalogues produits pour fabricants de mobilier et d'objets décoratifs.
La plateforme comprend :
- un moteur de génération de fiches produit ;
- un module de traduction assistée ;
- un connecteur API avec des places de marché B2B ;
- une bibliothèque d'images et de modèles 3D fournie par les clients ;
- un module documentaire pour notices, étiquettes et emballages.
Le siège initial serait fixé à Lyon 2e.
Un établissement secondaire à Paris est envisagé au second semestre 2026.
L'effectif prévu à l'immatriculation est de 5 personnes.
L'effectif prévu à 18 mois est de 14 personnes.
Le chiffre d'affaires prévisionnel hors taxes est de :
- 0 EUR sur l'exercice de lancement 2026, hors pilotes ;

- 1 350 000 EUR en 2028.
Le calendrier interne retient les dates suivantes :
- 12 janvier 2026 : validation du principe de création ;
- 2 février 2026 : ouverture de la data room fondateurs ;
- 18 février 2026 : premier échange avec un investisseur ;
- 4 mars 2026 : réception d'une offre commerciale distributeur ;

- 3 avril 2026 : dépôt souhaité du dossier d'immatriculation ;
- 15 avril 2026 : signature espérée du contrat distributeur ;

Les fondateurs sont les suivants.

## Posture cabinet (configurée)
Le cabinet fictif **Cabinet Veyrannes Associés** intervient comme conseil
transactionnel et corporate.
La posture configurée pour ce dossier est :
- documenter les hypothèses ;
- séparer les faits établis des éléments à compléter ;
- préparer un choix de forme sociale compréhensible par les fondateurs ;
- produire un premier brouillon exploitable de constitution ;
- identifier les pièces manquantes dans le corps du travail ;
- éviter de présenter les documents comme définitifs sans validation humaine.
Le cabinet travaille habituellement avec :
- un associé corporate pour la validation finale ;
- une collaboratrice droit des sociétés pour les statuts ;
- un conseil PI externe pour les actifs logiciels et marques ;
- un notaire partenaire lorsque la constitution implique un actif immobilier
  ou un droit réel immobilier ;
- un expert-comptable pour les valorisations et comptes prévisionnels.
La matrice interne d'approbation prévoit :
- validation collaboratrice pour brouillon de statuts ;
- validation associée pour choix de forme et clauses sensibles ;
- validation externe PI pour actifs logiciels, marque et droits d'auteur ;
- validation notaire partenaire pour tout document impliquant un lot immobilier ;
- validation client avant toute transmission à investisseur ou distributeur.
Le budget juridique prévu pour la constitution et les premiers actes connexes
est plafonné à 18 000 EUR HT hors débours.
Le budget ne couvre pas encore :
- pacte complet d'associés ;
- audit PI détaillé ;
- rapport d'évaluation ;
- intervention notariale ;
- négociation du contrat distributeur ;
- documentation de levée de fonds.
