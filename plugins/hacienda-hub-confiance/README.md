# Hub Confiance

## Mission

Permettre l'installation, l'évaluation, la désactivation et la mise à jour de skills ou plugins tiers avec une couche de confiance adaptée aux environnements juridiques.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-hub-confiance:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `naviguer-registre`
- `installer-skill`
- `evaluer-skill`
- `mise-a-jour-automatique`
- `desactiver-skill`
- `desinstaller-skill`
- `controle-connecteurs`
- `controle-licence`
- `controle-injection`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
