# Revue RGPD IA

## Objectif

Evaluer base legale, transparence, minimisation, droits, decisions automatisees, DPIA et transferts.

## Workflow

1. Lire registre IA et registre RGPD.
2. Identifier donnees personnelles, sensibles, mineurs ou decisions significatives.
3. Verifier documentation CNIL/EDPB si pertinente.
4. Marquer toute hypothese `[a verifier]`.
5. Escalader DPIA ou consultation DPO si necessaire.

## Sortie

Analyse RGPD, conditions, gaps, validation humaine, source officielle, Note de revue et dossier de preuve.
