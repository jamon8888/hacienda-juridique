# Gouvernance Ia

## Mission

Gouvernance IA : AI Act, RGPD, usages internes, contrats fournisseurs IA, politiques internes, analyse des risques.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-gouvernance-ia:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `triage-cas-usage-ia`
- `analyse-impact-ia`
- `reviser-contrat-ia`
- `rediger-politique-ia`
- `analyse-donnees-entrainement`
- `analyse-ecart-reglementaire-ia`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
