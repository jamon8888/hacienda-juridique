# Recherche Sociale

## Sources À Vérifier

- Code du travail.
- Convention collective KALI et IDCC applicable.
- Jurisprudence de la Cour de cassation.
- Conseil d'État si autorisation administrative, inspection du travail ou décision administrative.
- JORF/LODA pour les réformes ou textes récents.

## Analyse

1. Qualifier le sujet : relation individuelle, collective, santé-sécurité, paie, contentieux ou politique RH.
2. Identifier les articles du Code du travail applicables.
3. Identifier l'IDCC, la convention collective KALI, les accords d'entreprise et leur articulation.
4. Rechercher la jurisprudence de la Cour de cassation lorsque l'interprétation est discutée.
5. Marquer `[à vérifier]` toute source non consultée ou tout document utilisateur absent.

## Points De Validation Humaine

- licenciement, inaptitude, harcèlement, discrimination ou accident du travail ;
- contradiction Code du travail / KALI / accord d'entreprise ;
- contentieux devant le conseil de prud'hommes ;
- mesure collective, CSE, PSE ou réorganisation.

## Dossier De Preuve

Inclure références, identifiants Légifrance, IDCC, extraits KALI, décisions, pièces utilisateur, date de consultation et statut de vérification.
