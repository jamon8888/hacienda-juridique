# Analyse Rémunération Variable

## Sources À Vérifier

- Code du travail.
- Convention collective KALI et IDCC.
- Contrat de travail, plan de commissionnement, avenants et objectifs.
- Jurisprudence de la Cour de cassation.
- Bulletins, tableaux de calcul, communications commerciales ou RH.

## Analyse

1. Qualifier la rémunération : variable contractuelle, prime discrétionnaire, commission, bonus, objectif collectif.
2. Vérifier fixation des objectifs, caractère réalisable, information du salarié et période de référence.
3. Contrôler calcul, prorata, départ en cours d'année, absence, congés et modification unilatérale.
4. Croiser Code du travail, KALI/IDCC, contrat et jurisprudence.
5. Marquer `[à vérifier]` les chiffres, objectifs ou pièces absentes.

## Points De Validation Humaine

- modification de rémunération ;
- clause obscure ou objectifs non communiqués ;
- contentieux prud'homal ou départ conflictuel ;
- risque égalité de traitement ou discrimination.

## Dossier De Preuve

Inclure clause, objectifs, tableaux de calcul, bulletins, Code du travail, KALI/IDCC, jurisprudence et statut.
