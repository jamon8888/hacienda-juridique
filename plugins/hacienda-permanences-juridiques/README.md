# Permanences Juridiques

## Mission

Assister des permanences juridiques, cliniques professionnelles ou dispositifs pro bono supervisés.

## Sources

Ce plugin dépend de `hacienda-sources-officielles` pour les sources primaires.

## Commande De Démarrage

```text
/hacienda-permanences-juridiques:entretien-demarrage
```

## Skills Prévus

- `entretien-demarrage`
- `accueil-client`
- `qualification-probleme`
- `lettre-langage-clair`
- `controle-eligibilite`
- `statut-dossier`
- `controle-delais`
- `memo-handoff`

## Livrables

- dossier de preuve ;
- note ou mémo professionnel ;
- sources vérifiées ;
- points à relire manuellement.
