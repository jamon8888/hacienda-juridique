# Conflits Interets

## Objectif

Verifier si la permanence peut traiter le dossier ou doit orienter sans analyse de fond.

## Workflow

1. Identifier parties, adversaires, anciens dossiers, liens et financeurs.
2. Comparer avec les regles internes disponibles.
3. Limiter les donnees si conflit probable.
4. Marquer toute information manquante `[a verifier]`.
5. Exiger validation humaine avant poursuite.

## Sortie

Check conflit, statut, limites, Note de revue, dossier de preuve et Arbre de decision.
